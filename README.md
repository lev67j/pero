# Перо

Бесплатное приложение для Mac, чтобы писать и рисовать пером графического планшета прямо поверх PDF. Без распознавания фигур, без выделения текста пером, без лишних кнопок: взял перо — пишешь.

**Полностью бесплатно.** Без подписок, рекламы и регистрации. Открытый код (лицензия MIT).

## Что умеет

- **Открывает 5 видов файлов:** PDF, Word (DOCX, DOC), RTF, текст (TXT, Markdown) и картинки (PNG, JPEG, HEIC, TIFF). Всё показывается страницами, как в Просмотре.
- **Пишет пером планшета, мышью и трекпадом.** Рисует, пока нажата кнопка. Переключатель «перо / курсор» сверху (⌘D): курсором можно выделять текст и переходить по ссылкам.
- **10 инструментов:** ручка, карандаш, пунктир, перо (каллиграфическое), кисть, маркер, выделитель, мелок, акварель и ластик. У каждого своя толщина, она запоминается. Ластик стирает штрихи целиком, которых коснулся (⇧⌘E).
- **Цвета как в приложениях Apple.** 20 готовых цветов, системная палитра для любого другого и «Мои цвета», куда можно сохранить свои.
- **Лентой или по страницам.** Все страницы одной лентой или по одной; сбоку — кнопки перелистывания и номер страницы.
- **Убирает штрихами.** «Назад» убирает последний штрих, то есть всё, что нарисовано, не отрывая пера, или возвращает стёртое ластиком. «Вперёд» повторяет. Горячие клавиши ⌘Z и ⇧⌘Z.
- **Сохраняет само.** Записи сохраняются каждые 5 секунд, а также при переключении файла и при выходе. Нажимать «Сохранить» не нужно.
- **Экспортирует PDF.** Кнопка на панели сверху сохраняет PDF вместе с вашими записями.
- **Раскладывает по папкам.** В боковой панели можно создавать папки и папки в папках, переименовывать их, ставить значок и цвет. Файлы перетаскиваются из Finder и между папками.
- **Выгружает всю библиотеку одной папкой.** Кнопка внизу боковой панели (⇧⌘U) кладёт на рабочий стол папку «Перо — библиотека»: те же папки, подпапки и названия, а внутри PDF с записями. Дописали что-то или добавили файлы — та же кнопка обновляет эту папку: перезаписываются только новые и изменённые файлы, а PDF удалённых документов уходят в Корзину. Ваши собственные файлы в этой папке не трогаются. Папку можно переместить и переименовать — Перо её найдёт, а если нет, попросит показать, где она.

## Зачем

Конспекты, решение задач, правки в договорах и чертежах, подписи, пометки на лекциях. Встроенный Просмотр мешает писать от руки: превращает каракули в «идеальные» фигуры и выделяет текст вместо рисования. Перо просто рисует линию там, где прошло перо.

## Установка

1. Скачайте `Pero.zip` из раздела [Releases](https://github.com/lev67j/pero/releases) и распакуйте его.
2. Перетащите «Перо» в папку «Программы».
3. При первом запуске macOS предупредит, что приложение скачано из интернета и не проверено Apple. Откройте «Системные настройки → Конфиденциальность и безопасность» и нажмите «Всё равно открыть».

Нужна macOS 14 Sonoma или новее. Подходит для Mac на Apple Silicon и на Intel.

## Где лежат файлы

Библиотека хранится в `~/Library/Application Support/Pero/Library`. Каждый документ — это папка `Название.perodoc`, внутри неё лежат исходный `document.pdf` и записи в `ink.json`. Оригинальный PDF не меняется, поэтому записи можно убрать в любой момент.

## Сборка из исходников

```bash
git clone https://github.com/lev67j/pero.git
cd pero
./scripts/build-app.sh   # → build/Перо.app и build/Pero.zip
```

Нужен Xcode 15+ или просто Command Line Tools (`xcode-select --install`).
